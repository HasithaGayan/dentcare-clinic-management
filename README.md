# DentCare Clinic Management System

DentCare is a full-stack dental clinic management system built with React, Java 21, Spring Boot, MySQL, and REST APIs.

## Technology Stack

### Frontend
- React
- JavaScript
- Vite
- CSS

### Backend
- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- Bean Validation

### Database
- MySQL 8.4

### Tools
- IntelliJ IDEA
- Visual Studio Code
- Postman
- Draw.io
- Git and GitHub
